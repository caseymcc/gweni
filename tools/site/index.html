gweni

GUI Without Extravagant Nonsense is a C++17 retained-mode GUI library. Layout, hit-testing and change tracking run in an update phase that knows nothing of the rendering API, and the render phase touches only the controls that changed.

These pages are that library compiled to WebAssembly, drawing on WebGL 2 through the same OpenGLCore renderer the desktop builds use. They take the mouse, the wheel and the keyboard; text is grayscale-antialiased (the desktop's LCD text needs a blend mode WebGL 2 lacks).
